# Security

To report a security problem in a library listed in the mdBlocks Hub, or in
this repository's checks, use GitHub's private vulnerability reporting:
**Security → Report a vulnerability** on this repository. The maintainers can
remove a listing at once while they look into it.

For a problem that can be public, use the
[Report a library](https://github.com/mdblocks-labs/hub/issues/new?template=report.yml) form.
